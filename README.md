# Sub2Bar

在 macOS 菜单栏查看自部署 [sub2api](https://github.com/Wei-Shaw/sub2api) 的账号状态、并发与额度。

![macOS](https://img.shields.io/badge/macOS-14%2B-black)
![Swift](https://img.shields.io/badge/Swift-native-orange)

## 功能

- 菜单栏常驻，使用 SwiftUI 与 AppKit 构建原生界面。
- 顶部显示整个 sub2api 实例的统计；在设置中 Pin 账号，下方可逐个查看关注的账号。
- 查看当前并发、并发上限、调度状态和限流状态。
- 查看额度使用百分比、重置时间及 OpenAI 周额度估算。
- 查看已 Pin 账号的今日用量（标准价美元），按所选统计时区和 Admin 排除设置刷新；本周用量保留原有额度窗口口径。
- 普通 API Key / Bedrock 账号以三列展示统计：第一行是今日用量、今日账号费用和今日请求，第二行是今日 Token、今日实际消费。实际消费不要求配置订阅，并遵循 Admin 排除设置；Token 使用 K/M/B 紧凑显示。按 sub2api 配置显示日／周／总限额，不套用 OAuth 窗口或订阅周期。
- OAuth 账号可在本地配置月订阅价格和每月续费日，查看各自本周期实际扣费及订阅成本；可独立设置实际消费和订阅成本的货币符号（原样显示、不换算金额）。
- 顶部第一行是全局“今日实际消费”和“今日标准费用”，第二行是全局“近 30 天消费”和“总并发”。全局统计不受 Pin、账号类型或订阅配置影响，未 Pin 账号时也可查看。
- 底部“排除 Admin”快速开关与设置同步并记住选择，同时影响全局及账号今日实际消费、今日标准费用，以及订阅周期实际消费；总并发、额度、账号费用和订阅成本不受影响。
- 面板一次显示一个已 Pin 账号，按保存的顺序左右切换；详情展开直接撑高，不使用竖向滚动。
- 打开面板自动刷新，显示刷新倒计时；关闭面板后停止轮询。

主要适配 OpenAI、Anthropic OAuth / SetupToken 和普通 API Key 账号，仅提供只读监控。平台专属额度能力单独判断，不把所有非 OAuth 账号一概视为无额度。

## 安装

支持 **macOS 14 及以上**，兼容 Apple Silicon 和 Intel Mac。

1. 从 [Releases](https://github.com/Yibael/sub2bar/releases) 下载 `Sub2Bar-<版本>-macOS-universal.zip`。
2. 解压，将 `Sub2Bar.app` 移到“应用程序”并打开。
3. 点击菜单栏图标进入面板。

当前安装包未经过 Apple 公证，请核对下载来源并遵循系统安全提示。若暂无 Release，可按下方步骤从源码构建。

## 上手

1. 打开 **设置 → 连接**，填写服务器 URL 和 sub2api **Admin API Key**。
2. 点击字段旁的“测试连接”，确认后点击“保存设置”。
3. 进入“账号管理”自动加载账号列表；点击图钉将账号加入“面板切换”分组，用序号旁的上下箭头调整顺序。点击 OAuth 账号的订阅栏可填写或编辑月价和每月续费日。
4. 在“消费统计”选择是否包含 Admin 用量（默认包含）、统计时区，以及实际消费／订阅成本的货币符号（默认均为 `$`）。底部可快速切换是否排除 Admin。订阅配置仅用于下方 OAuth 账号的周期信息，不影响顶部全局统计。
5. 打开菜单栏面板，开始查看数据。

保存设置不会发起连接；打开面板后自动查询。刷新设置分三类：账号状态（默认 2 秒，含全局并发及账号请求数、Token、账号费用）、额度与费用（默认 30 秒，可能访问上游）、消费统计（默认 2 秒，查询本地数据库的标准费用、实际消费和订阅周期消费）。修改间隔保留缓存与进行中的请求，只调整对应期限；关闭面板或休眠停止全部轮询。

顶部四张统计卡片首次加载时在数字位置显示加载动画；后续刷新保留已有数值，请求超过 200ms 时在右上角显示迷你加载标识，完成后更新数字并移除标识。刷新失败保留同一统计范围内的上次完整结果，并显示可悬停查看的提示；没有历史结果时显示未知，不冒充零。切换服务器、密钥或统计范围后，不复用无关旧值。

账号管理优先展示内存缓存：首次进入自动加载，1 分钟内再次进入不请求，过期后保留旧列表并后台刷新；手动刷新可立即获取。失败保留列表及上次更新时间，切换服务器或密钥会清空缓存；账号目录不持续轮询、不落盘。

面板支持左右按钮、方向键以及折叠卡片横向拖动切换；展开详情后保留文本选择，不通过拖动切换。切换和调整顺序不发新请求、不重置额度冷却；顶部始终为全局数据。

切换账号独立于请求状态，立即更新当前页，不等待网络完成；已有数据显示缓存，尚未获取的数据位置显示 loading，首次尚无账号详情时显示所选账号 ID 和加载提示。选中状态仅刷新卡片和分页控件，不触发全账号汇总重算；轮询响应按批次提交快照，订阅周期在有效日期／时区内复用，减少主线程重复工作。

账号读取异常集中在“已 Pin N 个账号”旁的警告图标，悬停可查看账号名称、失败项目和原因，不再显示撑高面板的错误横幅。账号详情失败只置灰对应卡片并保留缓存；仅统计或额度失败时，只标记受影响的字段或额度区域。置灰仅是视觉提示，仍可切换、展开详情和手动刷新；悬停与切换不发请求，不改变原有自动重试及刷新间隔。

订阅消费按独立的实际消费间隔查询 sub2api 本地扣费统计（含倍率），不查询上游额度。以指定时区的续费日零点划分月周期，显示续费日至下月续费日前一天（例如 9 月 15 日至 10 月 14 日，首尾均包含）；短月取月末，不等同于精确扣款时刻。关闭 Admin 统计依据当前用户角色排除。月订阅成本不按天摊销；部分消费读取失败时不展示不完整总额。订阅元数据仅保存本地，取消 Pin 不会删除。

顶部近 30 天消费为所选时区今天及之前 29 个日历日的实际扣费，日期包含首尾；不是自然月或订阅周期。今日标准费用读取 `total_cost`，实际消费读取 `total_actual_cost`，二者不能互换。排除 Admin 时分别减去所有当前 Admin 用户在相同日期、账号范围下的小计；识别 Admin 失败时不回退为包含 Admin。跨日或变更统计口径后不复用旧金额。全局并发使用 `ops/concurrency` 的账号维度去重汇总，需要服务端启用实时监控；接口不可用时提示失败，不用 Pin 并发或零值代替。

普通 API 账号的限额来自账号详情，不调用不支持的 OAuth 额度接口；随账号状态间隔刷新。今日账号费用使用 sub2api 的账号统计价格和倍率，并非上游对账账单；它与请求数、Token 继续采用服务端今日口径。今日标准用量和实际消费采用所选统计时区及 Admin 设置。未配置、已用金额未知和请求失败分别处理，缺失统计不填零。普通 API 不使用订阅周期，但纳入全局消费统计。

服务器默认使用 HTTPS；如需 HTTP，请在设置中显式开启。

## 从源码构建

需要 Xcode 26.3 或更新版本。

```sh
git clone https://github.com/Yibael/sub2bar.git
cd sub2bar
swift test
bash scripts/build-app.sh dist native
open dist/Sub2Bar.app
```

构建 Apple Silicon / Intel 通用包：

```sh
bash scripts/build-app.sh dist universal
```
